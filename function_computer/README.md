# 一元多项式计算器（带余除法 + 最大公因数 + 裴蜀等式）

在有理数域 **Q** 上对两个一元多项式 f(x)、g(x)：

1. **带余除法**：f = g·Q + R，deg R < deg g；
2. **最大公因数**：辗转相除法求 gcd(f, g)；
3. **裴蜀等式**：用扩展欧几里得算法求 u(x)、v(x) 使

   ```
   u(x)·f(x) + v(x)·g(x) = gcd(f(x), g(x))
   ```

系数允许整数、分数或小数（内部按分数精确运算，无浮点误差）。

| 文件 | 说明 |
|---|---|
| `poly_calc.cpp` | 控制台版（纯 C++11，无第三方依赖） |
| `poly_ui.cpp` | EasyX 图形界面版（高清 DPI 自适应 + 按钮交互） |

## 三、算法说明

### 带余除法

逐次消去被除式的最高次项：第 i 步取 `factor = r[i] / g[deg g]`，
`r -= factor * x^(i-deg g) * g`。因为系数在域 Q 上，除法总可以做。

### 扩展欧几里得（求 u, v）

对余式序列 `r[i] = r[i-2] - q[i]·r[i-1]` 同步维护两个"系数多项式"：

```
r[i] = s[i]·f + t[i]·g
s[i] = s[i-2] - q[i]·s[i-1]      s[0]=1, s[1]=0
t[i] = t[i-2] - q[i]·t[i-1]      t[0]=0, t[1]=1
```

迭代到 `r[k+1] = 0` 时，`r[k] = s[k]·f + t[k]·g`，再把两边同除 `r[k]` 的首项系数
（归一化成首一），即得

```
u = s[k]/lc(r[k]),  v = t[k]/lc(r[k]),  且 u·f + v·g = gcd(f, g)
```

**u、v 不唯一**：对任意多项式 k(x)，`u + k·(g/d)`、`v − k·(f/d)` 仍是解（d = gcd）。

### 特例

| 情形 | 带余除法 | gcd | 裴蜀等式 |
|---|---|---|---|
| `deg f < deg g` | Q = 0, R = f | 同左 | 正常求解 |
| g 是零多项式 | 无意义并提示 | `gcd(f, 0) = f`（首一化） | u = 1/lc(f), v = 0 |
| f、g 都是零多项式 | 无意义 | `0` | 0 = 0，u、v 任取 |
| 常数多项式（如 g = 3） | 照常 | 照常 | 照常 |

> 有理系数域上 gcd 只在「相差一个非零常数倍」意义下唯一，程序统一以首一形式为代表。

## 四、实现要点

- 自定义 `Frac` 有理数类：恒约分、分母恒正，加减乘除全程精确；
- 乘除法先交叉约分，抑制系数膨胀；中间乘加用 `__int128`，超出 64 位给溢出警告；
- 多项式 `vector<Frac>`，`c[i]` 为 x^i 系数，空向量表示零多项式；
- 界面版与控制台版共用同一套运算内核（`Frac` + `Poly` + `polyDivMod` / `polyGcd` / `polyExtGcd`）。
